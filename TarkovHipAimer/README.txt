Tarkov Hip Aimer — by Leo   v3.1

【这是什么】
塔科夫腰射用的屏幕准星：在屏幕上画一个圆圈，跟着你的走路、侧身、开枪、跳跃、换手移动，
帮你估计不开镜时子弹大概落在哪里。每把枪可以存一套自己的配置。

【安装 / 运行】
1. 把压缩包解压到一个固定的文件夹（比如 D:\TarkovHipAimer）。
2. 双击 Start-HipAimer.bat。第一次会自动编译出 TarkovHipAimer.exe（用 Windows 自带的 .NET 4），
   然后弹出管理员确认，点“是”。以后再双击也一样，已经在运行时会直接打开设置窗口。
3. 程序在右下角托盘里，双击托盘图标打开设置。
4. 请设置自己的按键，和分辨率，仅需要点击获取分辨率即可。
5. 目前的设置可以覆盖90%以上的准确率，但还需不同玩家根据自己的人物角色和常用配装进行调整，建议装一个镭射然后找一面墙扫射，调整wasd qe 和 后坐力。

【常用按键与开镜同步】（可配置项见“按键”页）
- F12：开 / 关准星。关了再开会回到正常手、取消强化准星。
- 鼠标侧键1（下侧键）：换手。换手后准星默认左右镜像（“换手”页可以逐项改），并换成“换手颜色”（默认橙色），可以在“外观”页改。
- 鼠标侧键2（上侧键）：强化准星，按一下变成更大更亮的准星，再按一下恢复（外观可以在“外观”页改）。
- 开镜时准星自动隐藏，“按键”页的开镜方式需要与游戏一致（按住 / 点一下切换）。自由视角（中键按住）时也会隐藏。
- 开镜键为鼠标右键时，Alt + 右键切倍率/准星样式、Ctrl + 右键切瞄具不会改变工具记录的开镜状态。先松 Alt/Ctrl、右键仍按住时也不会补触发开镜；单独右键照常生效。
- 点一下切换开镜时，默认 Tab、Esc 会让工具重新认定为未开镜，避免打开背包后显隐反转。可在“按键 → 取消开镜 → 配置取消键”中添加、移除或清空；不会向游戏发送按键。
- 点一下切换开镜时，有效前进期间新按下 Shift，会让工具重新认定为未开镜、恢复腰射准星；默认前进键是 W，前进改键后跟随新设置。先按住 Shift 屏息再按前进键不会取消开镜；持续按住 Shift 时停步、再次前进或松开后退恢复前进也不会再次取消，需前进时松开再按 Shift。按住开镜方式仍按原规则处理。
- 点一下切换开镜时，默认 Ctrl + R 检查弹匣会立即清除开镜记录、显示准星，并在之后 3 秒内忽略开镜点击。可在“按键 → 检查弹匣 → 配置检查保护”修改组合键和时间（0～30 秒，0 表示关闭）；恢复默认按键也会恢复 Ctrl + R 和 3 秒。旧设置自动使用默认值。
- 检查保护从组合刚按下时计时，长按不会不断延长；重新按下会重新计时。时间结束时，仍按住的开镜键不会补触发，需松开后再按。它不会向游戏发送按键，3 秒是统一保护时间，不代表所有枪械的实际动画时长。
- 点一下切换开镜时，左 Alt + W/S 盲射会清除开镜记录、显示准星，盲射按住期间的开镜点击不计入状态；松开后新的开镜点击正常生效。
- 点一下切换开镜时，按默认数字 1/2/3 切枪会立即清除开镜记录、显示准星，并在之后 1.5 秒内忽略开镜点击；每次新的切枪重新计时，长按同一个键不会延长。到期时仍按住的开镜键不会补触发，需松开再按。
- 按默认 U 拔刀、G 拿雷同样立即清除开镜记录。持刀时不把右键攻击记为开镜，按 1/2/3 切回枪械并等待 1.5 秒后恢复；U 按拔刀处理，双击 U 快速近战自动回枪目前不单独识别。
- 持雷时不把右键低抛记为开镜；拿雷后新按下鼠标左键或右键才视为开始投掷，投掷键全部松开后等待 1.5 秒恢复开镜判断。拿雷前已经按住的旧开镜右键，其松开不视为投掷。也可直接按 1/2/3 切回枪械并等待 1.5 秒恢复。上述武器键及 1.5 秒为本次固定规则。
- 背包内可正常右键物品，最终通过设置的取消键退出后，准星恢复正确显示；背包内显隐不单独控制。
- 空格：跳跃时准星跟着上下动（“跳跃”页）。

【换手自定义】（“换手”页）
换手后的偏移默认是正常手的左右镜像（灰色“自动”，会跟着正常手一起变）。
哪一格不准就直接改，改过的格子用你自己的数；点“恢复自动”回到自动，“全部恢复自动”一次全恢复。

【只在塔科夫前台时显示】（“其他”页，默认开）
切到别的窗口时准星自动不显示，也不会读你的按键；切回游戏自动出现。
靠窗口标题判断，默认“EscapeFromTarkov”。如果没反应，点“从打开的窗口里选”选游戏窗口。
打开设置窗口时准星照样显示，方便调参。

【开机自动启动】（“其他”页，默认关）
勾上后登录 Windows 会自动在托盘里启动，不弹设置窗口。移动了文件夹也没关系，下次手动启动时会自动更新。

【卸载】
1. “其他”页取消“开机自动启动”。
2. 右键托盘图标 → 退出。
3. 删除整个文件夹（设置都存在里面的 settings.json）。

【声明】
BSG 禁止影响游戏客户端的软件。本程序只读取按键状态、在屏幕上画一个窗口，不碰游戏进程和内存.
