# 检查弹匣与盲射显隐修复

日期：2026-11-13。

## 本次约定

- 点一下切换开镜时，默认 Ctrl+R 触发检查弹匣保护：立即将记录清为未开镜、显示瞄准点，之后 3 秒内不计入开镜点击。
- 检查前的开镜记录不保留。这是用户后续明确调整的规则。
- 组合键和时长在“按键 → 检查弹匣 → 配置检查保护”中编辑；支持 Ctrl、Alt、Shift 组合及键盘或鼠标主键。
- 时长范围为 0～30 秒，步进 0.1 秒；0 秒关闭这项处理。旧配置缺少新字段时自动采用 Ctrl+R 和 3 秒。
- 长按组合只触发一次，松开后重新按下会重新计时。到期时仍按住的开镜键不补触发，需要松开再按。
- 计时使用真实经过时间，不受运动计算的长帧限幅和预览速度影响。它是用户指定的统一保护时间，不是游戏实测动画时长。
- 左 Alt+W 或左 Alt+S 盲射立即清除开镜记录；盲射按住期间的开镜点击不计入状态，松开后的新点击正常生效。
- 这两项新增同步规则用于点一下切换开镜，按住开镜方式沿用原行为。
- 保留现有取消键、奔跑、切瞄具、前台限制和预览逻辑，不修改游戏配置，不向游戏发送按键。

## 游戏内验收

1. 退出旧程序后启动新版，检查“按键 → 检查弹匣”摘要为 Ctrl+R、3 秒，并确认开镜方式为点一下切换。
2. 先右键开镜，再按 Ctrl+R，瞄准点应立即显示。松开 Ctrl，在三秒内多次点右键，瞄准点应保持显示。
3. 三秒到期时，如果右键仍按住，瞄准点不应突然隐藏。松开再按右键后应正常隐藏，下一次右键应正常显示。
4. 分别尝试左 Alt+W 和左 Alt+S；开始盲射时应显示瞄准点，盲射期间点右键不能使记录翻转；结束后新右键照常开镜。
5. 将检查组合和时长改为另一组与游戏一致的设置，保存并重启，确认保留；设置为零秒时应停止这项保护。
